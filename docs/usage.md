# 使用指南

[返回 README](../README.md)

## 选择输入

| 输入 | 支持格式 | 行为 |
| --- | --- | --- |
| 公开地址 | 对应链的合法地址 | 只查询格式兼容的网络，不保存私钥 |
| 助记词 | 12/24 个 BIP-39 英文单词 | 校验词库、词数和校验和，按默认路径派生地址 |
| 私钥 | EVM/TRON：32 字节 hex；Bitcoin：压缩主网 WIF 或 hex；Solana：Base58/JSON 的 32 字节 seed 或 64 字节密钥对 | 查询可由该密钥格式推导的地址体系 |

选择「全部匹配网络」时，EVM 地址可查询 10 条 EVM 主网；Solana 地址只查 Solana。公开地址不能派生其他地址体系。hex 私钥可匹配 EVM、Bitcoin 与 TRON，不能当作 Solana 的 Ed25519 密钥。

助记词可逐词编辑或整组导入，支持常见标点、换行和连续序号。输入错误会给出校验提示，不猜词、不修复校验和、不自动重排。生成或编辑不会发起链上查询，点击查询后才读取余额。

## 默认派生路径

| 地址体系 | 路径 | 查询范围 |
| --- | --- | --- |
| EVM | `m/44'/60'/0'/0/0` | 第一个账户的地址，10 条 EVM 网络共享 |
| Bitcoin | `m/84'/0'/0'/0/0` | 第一个原生 SegWit 接收地址，单独显示未确认净变化 |
| Solana | `m/44'/501'/0'/0'` | Ed25519 地址的 finalized SOL 和可完整枚举的白名单代币 |
| TRON | `m/44'/195'/0'/0/0` | 第一个地址的已确认 TRX 和白名单 USDT |

不支持额外 BIP-39 口令、自定义路径、账户扫描或 gap limit 扫描。如果目标钱包使用其他路径，请直接输入它的公开地址。Bitcoin 的 P2PKH、P2SH、Taproot 地址可直接查询；私钥输入固定生成原生 SegWit 地址。

## 代币余额

网页自动查询 [common-tokens.mjs](../common-tokens.mjs) 收录的常见代币，按网络和合约/mint 识别，按币种展示。明确为同一版本的跨链金额精确汇总，桥接币、包装币和 Binance-Peg 版本分开。

- EVM：原生币与代币在同一区块读取，可选择单链并填写 ERC-20 合约或自定义 HTTPS RPC。
- Solana：分别枚举 SPL 与 Token-2022 的全部 owner token accounts，按 mint 精确合计；枚举不可用时跳过对应程序的代币，不回退到标准 ATA 子集。
- TRON：通过 Solidity 节点只读查询 USDT，不签名、不广播、不消耗能量。
- Bitcoin：只统计原生 BTC，不统计 WBTC、BTCB 等包装资产。

不同链的查询时间不保证一致。失败或不完整的结果不显示、不汇总，也不当作零。公开测试钱包会显示橙色标签，但标签只覆盖内置已知样例，不能判断其他密钥是否安全。

## 查询历史

点击「查看历史记录」展开列表。每组助记词、每个私钥或公开地址只对应一条记录，重复输入更新原记录；同组多链地址不会拆成多条钱包记录。列表按钱包分页，支持余额和密钥筛选。

展开后可查看代币余额、网络明细与地址。助记词在记录顶部统一提供「显示助记词」入口；各链地址卡片分别显示私钥。明文仅在点击后读取，收起记录或查询版本变化后隐藏。

点击「重新查询余额」，选择单链或全部适用网络。查询时保留原余额，成功后才更新；全部失败不会清空已有结果。公开地址重查不需要读取私钥。旧记录若没有保存助记词，不能由私钥反推，需重新导入原词组。

## 定时任务

历史区域显示创建状态、累计数量和最近时间，可暂停或恢复。暂停后不再创建钱包，已有查询和历史补查会继续完成。关闭网页不影响服务端任务。

服务端定时生成随机助记词用于功能实验，并非发现已有钱包的方式。新生成的钱包通常为零余额。启用方式与执行间隔见[部署配置](operations.md#运行配置)。

## 手机安装 PWA

手机需能访问运行中的服务。完整 PWA 安装与 Service Worker 需要手机信任的 HTTPS 地址；桌面 localhost 可作为开发环境。

- iPhone/iPad：Safari → 分享 → 添加到主屏幕。
- Android：Chrome/Edge → 页面「安装应用」，或浏览器菜单中的安装入口。

普通局域网 HTTP 地址可能只能添加快捷方式。PWA 不会把后台任务移到手机；余额查询和历史仍依赖本地服务。离线只显示通用连接提示，不缓存钱包编辑页、密钥、历史或 RPC 响应。

## CLI 参数

```bash
npm start -- --help
npm start -- --chain ethereum
npm start -- --chain base --rpc https://mainnet.base.org
npm start -- --chain ethereum --address 0x627306090abaB3A6e1400e9345bC60c78a8BEf57
```

查询指定代币时，使用 `--chain ethereum --token <ERC20_CONTRACT_ADDRESS>`，将占位符替换为合约地址。CLI 不支持助记词，只在交互式终端隐藏读取私钥；不接受私钥命令行参数、环境变量、文件或管道。失败会返回非零退出码。
